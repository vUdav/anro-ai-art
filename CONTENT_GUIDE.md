# Как менять контент на сайте (без кода)

Сайт статичный, но контентом можно управлять через удобную визуальную форму — **Sveltia CMS** (на движке, совместимом с Decap CMS). Ничего не ломается: изменения сохраняются в репозиторий, а сайт автоматически пересобирается.

## Вход в панель

1. Откройте **https://anroai.art/admin/**
2. Нажмите **Login with GitHub** и войдите под своим GitHub-аккаунтом (должен иметь доступ к репозиторию).
3. После входа вы увидите разделы: **Работы, Отзывы, Услуги, Тексты разделов**.

> После сохранения любых правок сайт обновляется автоматически за 2–3 минуты (идёт пересборка). Обновите страницу через пару минут.

## Три языка

Почти у каждого поля есть вкладки **RU / EN / BE**. Заполняйте все три — тогда посетитель на любом языке увидит перевод. Если оставить пусто, подставится русский вариант.

## Добавить новую работу

1. Раздел **Работы → New Работа**.
2. Заполните:
   - **ID** — латиницей, уникально, напр. `neon-cover-02` (используется в имени файла).
   - **Тип** — «image» для картинки, «video» для видео.
   - **Категория** — обложки / мокапы / фотосессии / эскизы / реклама / иллюстрации.
   - **Файл** — загрузите изображение (jpg/png/webp) или видео (mp4).
   - **Постер для видео** — кадр-превью (только для видео).
   - **Порядок сортировки** — меньше число = выше в списке.
   - **Название / Alt / Описание** — на трёх языках.
3. **Publish → Publish now**.

### Про видео (важно)

- Храните видео **коротким и сжатым**: до ~5–10 МБ, формат **mp4 (H.264)**. GitHub не принимает файлы больше 100 МБ.
- Для тяжёлого видео используйте поле **«Внешняя ссылка на видео»** (YouTube/Vimeo/Cloudflare) вместо загрузки файла.
- Всегда добавляйте **постер** — он показывается на карточке до запуска.

## Изменить тексты разделов

Раздел **Тексты разделов**:
- **Первый экран (Hero)** — имя, роль, заголовок, подзаголовок, кнопка.
- **Обо мне** — фото, заголовок, биография, список регалий.
- **Контакты** — ссылки на Telegram/Instagram, email, заголовок и текст.

## Отзывы и услуги

Аналогично работам: разделы **Отзывы** и **Услуги**, кнопка **New**, заполнить поля на трёх языках, **Publish**.

## Что нужно настроить один раз (для разработчика)

Чтобы вход в `/admin` работал, нужен бесплатный OAuth-брокер (сервера у сайта нет).

1. **GitHub OAuth App**: Settings → Developer settings → OAuth Apps → New.
   - Homepage URL: `https://anroai.art`
   - Authorization callback URL: адрес воркера (см. ниже) + `/callback`.
2. **Cloudflare Worker** `sveltia-cms-auth` (бесплатно):
   - Репозиторий и инструкция: https://github.com/sveltia/sveltia-cms-auth
   - Задать переменные воркера `GITHUB_CLIENT_ID` и `GITHUB_CLIENT_SECRET` из OAuth App.
3. В [public/admin/config.yml](public/admin/config.yml):
   - заменить `OWNER` в `repo:` на ваш GitHub-логин;
   - раскомментировать и указать `base_url` = адрес воркера.

### Локальная правка без входа (для разработчика)

Можно редактировать прямо на компьютере: запустите `npm run dev`, откройте `http://localhost:5173/admin/` — Sveltia предложит **Work with Local Repository** и будет писать изменения в файлы проекта без GitHub.

## Social-превью (OG-картинка)

Сейчас используется `public/og-default.svg`. Для лучшего превью в Telegram/соцсетях замените его на реальный **1200×630 .jpg** и поправьте путь `OG_IMAGE` в [src/composables/useSeo.ts](src/composables/useSeo.ts).
